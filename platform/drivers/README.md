# Prebuilt device driver

`prebuilt/zt9101_ztopmac_usb.ko` is the tested ZT9101 USB Wi-Fi module for
the exact Pearl kernel `4.1.13-cl-som-am57x-ti-3.0`. The adjacent firmware
and configuration files are copied to the SD boot partition. The source and
patch are intentionally not part of this repository.

The binary's provenance and test result are recorded in
[research/mimic-zt9101-wifi.md](../../research/mimic-zt9101-wifi.md).
